# E-Authentication
A simple web-based E-Authentication system developed using Python and Flask.
E-Authentication System

About the Project
E-Authentication is a simple web-based authentication system developed using Python and Flask.

Technologies Used
1.Python
2.Flask
3.HTML
4.CSS

Features
•User authentication
•Login system
•Simple and user-friendly interface
•Secure authentication process

Project Purpose
•This project was developed to understand the basic concepts of web application development and user authentication using Python Flask.

How to Run
•Install Python and Flask.
•Open the project folder.
•Run the Flask application.
•Open the local server in a web browser.
